# Rejections

Every rejected submission gets a reason. The bar is the product, so the reasoning behind it is published rather than left in a closed pull request.

Entries are added here when a submission is declined, with the date, what was proposed, and the one-line reason. Removals of previously listed entries are recorded the same way.

As of 2026-10-03 five third-party submissions have been received. Four were merged and one is still under review, so none has been declined yet and the table fills from the first decline. Entries dropped during initial curation predate this log.
